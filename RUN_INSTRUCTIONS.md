# RDSim Run Instructions (Windows + WSL2)

This file is a practical, presentation-ready runbook for this project.

## 1) Prerequisites

Use this environment for best compatibility:
- Windows host
- WSL2 Ubuntu 22.04
- ROS 2 Humble
- Gazebo Classic 11

## 2) First-Time Setup

Open Ubuntu 22.04 (WSL terminal), then run:

```bash
set -e

# ROS 2 Humble environment
source /opt/ros/humble/setup.bash

# Optional but recommended for Gazebo assets
export GAZEBO_RESOURCE_PATH=/usr/share/gazebo-11:$GAZEBO_RESOURCE_PATH

# From your ROS workspace root
cd ~/ros2_ws

# Install dependencies
rosdep update
rosdep install --ignore-src --rosdistro humble --from-paths src/RDSim src/RDSim/rdsim_submodules/navigation2 -y

# Build
colcon build --symlink-install --parallel-workers 8

# Source workspace overlays
source ~/ros2_ws/install/local_setup.bash
```

## 3) Run The Full Navigation Demo

In a WSL terminal:

```bash
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/local_setup.bash
export GAZEBO_MODEL_DATABASE_URI=
ros2 launch rdsim_gazebo rdsim_gps_navigation.launch.py
```

Expected windows:
- Gazebo: world + robot
- RViz: map + navigation tools

## 4) Drive The Demo In RViz

1. Click 2D Pose Estimate and set the robot pose once.
2. Click Nav2 Goal and place a reachable goal.
3. Watch movement in Gazebo and planned path in RViz.

## 5) Live Validation Commands (Optional, Good For Presentation)

Open another WSL terminal:

```bash
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/local_setup.bash

# Control outputs generated by Nav2 controller
ros2 topic echo /cmd_vel
```

In another terminal (optional):

```bash
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/local_setup.bash

# Navigation status stream
ros2 topic echo /status
```

## 6) Useful Health Checks

```bash
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/local_setup.bash

ros2 lifecycle get /bt_navigator
ros2 lifecycle get /controller_server
ros2 lifecycle get /planner_server
ros2 lifecycle get /map_server
```

All should report active during normal operation.

## 7) Stop / Cleanup

- Press Ctrl+C in the launch terminal to stop all launched nodes.
- If Gazebo processes are stuck:

```bash
pkill -9 gzserver gzclient gazebo || true
```

- If Gazebo UI opens as tiny/black due to bad saved UI config:

```bash
mv ~/.gazebo/gui.ini ~/.gazebo/gui.ini.bak 2>/dev/null || true
```

## 8) Minimal Presentation Script (3 Minutes)

1. Problem: autonomous outdoor delivery needs robust localization and planning.
2. System: RDSim integrates Gazebo simulation, localization, and Nav2 navigation in ROS 2.
3. Demo: set initial pose, send goal in RViz, robot moves in Gazebo.
4. Evidence: show /cmd_vel and /status output while robot navigates.
5. Conclusion: end-to-end autonomous navigation loop is validated in simulation.
